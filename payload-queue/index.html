What is real and what is placeholder

  • Working locally: record framing (magic, version, size, data), per-packet sequence + CRC-32, a queue that picks the next file at a file boundary, a receiver that rebuilds and verifies bytes. A Python copy produces the same bytes (tested).
  • Placeholder: video and audio packets are dummy filler; the programme is never decoded or changed. Zero padding of the last packet is a mock choice.
  • Not here: FFmpeg, TSDuck, SRT, PES/AC-3 wrapping, any error correction, the live receivers. Sequence and CRC only detect loss; nothing repairs it.
