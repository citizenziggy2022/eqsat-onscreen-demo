# eQsat OnScreen — live demo

**Live demo:** https://citizenziggy2022.github.io/eqsat-onscreen-demo/

The eQsat OnScreen / eQsat Hotbird broadcast screen (Hotbird 13E): Ukraine air-raid alert map, news panels, bulletins, photo stills, regional clocks, ticker and live radio.

This repository holds only the built web app (static files served by GitHub Pages). The content — stills, ticker, bulletins, clocks, channel settings and the news/alert feed — is read live from the app's Base44 backend, so changes made in the Base44 control panel show up here too.

Built Nov 8, 2026. Best viewed full screen at 1920×1080.
